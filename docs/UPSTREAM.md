# Upstream and source provenance

MosaClip is an independently maintained derivative of
[PasteMemo by lifedever](https://github.com/lifedever/PasteMemo-app).
Thank you to the original author and contributors for releasing the clipboard,
persistence, OCR, search and paste foundation under GPL-3.0.

- Initial upstream baseline: `15e827cc4757cecd597ba6344041a070971286aa`.
- Selectively imported upstream v1.15 snapshot:
  `d9defcaddb9464a833669555c8b4fc053a9ae5d5`.
- MosaClip 0.4.7 development baseline for this public source release:
  `b912b19123105d590e4faf68aed8edb600b2c58d`.

This public repository begins with a reviewed complete source snapshot. Earlier
development history is retained separately rather than republished. Original
copyrights, dependency notices and GPL terms remain intact.

MosaClip adds the card/list workspace, rendered/raw Markdown and SVG details,
color previews, storage management and adapted automation output controls.
Selected v1.15 functionality was ported while retaining MosaClip's workspace,
Quick Panel appearance and privacy boundaries. Upstream TracklessScroller and
cloud AI implementations were not imported.
